# B² PolyCrystal

Настольная программа на Python для сегментации зёрен на SEM-снимках предобученной MobileSAM. Интерфейс на русском языке, промежуточные стадии, пакетная обработка, морфометрия и ручная корректировка. Модель **запускается**, обучение модели на данном наборе не проводилось.

## Установка в новом месте

Проверено на Python 3.12 и macOS arm64. Нужен Python 3.12, около 3 ГБ места для окружения. Интернет нужен только для установки библиотек; модель, исходные снимки, результаты и веса уже включены.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python main.py
```

Windows: `py -3.12 -m venv .venv`, затем `.venv\Scripts\python -m pip install -r requirements.txt` и `Запустить.bat`. Windows отдельно проверена. Обработка принудительно выполняется на CPU. `requirements.txt` содержит прямые зависимости (библиотеки для установки).

MobileSAM включена в `vendor/mobile_sam` без изменения исходников; `main.py` подключает этот каталог. Никаких ключей API и внешних сервисов для обработки не требуется.

## Рабочий процесс

1. Добавьте снимки. Проверьте исходник и число строк, отрезаемых снизу. Служебная полоса микроскопа не является поверхностью образца.
2. При необходимости задайте масштаб отдельно для каждого файла: длину линейки в пикселях и соответствующую длину в микрометрах. Программа делит физическую длину на пиксельную. Автоматического чтения шкалы нет. Если масштаб не подтверждён, оставьте пиксели.
3. Запустите текущий снимок либо выделенные файлы. При отсутствии выделения пакетная кнопка обработает весь список. Выполнение идёт в фоновом потоке, отмена заканчивает текущий снимок.
4. Просмотрите **Original, Preprocessed, Edge map, Raw segmentation, Postprocessed segmentation, Overlay on original** на шести вкладках.
5. На вкладке результата выберите маску щелчком; Ctrl позволяет выбрать несколько. Доступны объединение, удаление, назначение класса, добавление области полигоном, изменение границы полигоном и разделение нарисованной линией. Enter или двойной щелчок завершает полигон/линию, Esc отменяет рисование. У разделяющей линии концы должны выйти за выбранный объект. Ctrl+Z отменяет правку.
6. Сохраните результат. Сессия включает исправленные маски, классы, журнал действий и параметры. Повторное открытие не требует запуска сети. Не перезаписывайте исходную автоматическую сессию, если она нужна для сравнения.

Классы «Зерно», «Артефакт», «Неопределено» назначает пользователь. Это ручная классификация, нейросеть эти классы не распознаёт. Все автоматические предложения получают исходный класс «Зерно» и требуют визуального контроля. Изменение геометрии обнуляет модельную оценку соответствующей маски; ручные классы и физический масштаб сохраняются.

## Использованный метод

Опубликованные компоненты: **MobileSAM vit_t / TinyViT + SAM AutomaticMaskGenerator**, OpenCV CLAHE, связные компоненты и `regionprops` scikit-image.

Зафиксированные параметры эксперимента:

- При импульсном шуме можно включить медианный фильтр 3 × 3 перед CLAHE; по умолчанию выключен, чтобы не сглаживать тонкие границы.
- CLAHE clipLimit 2.0, сетка 8 × 8 областей; 0 отключает CLAHE.
- Сетка подсказок 24 × 24, по 32 точки в батче.
- predicted IoU ≥ 0.88, stability ≥ 0.95, NMS по рамкам 0.30; дополнительных слоёв кропов нет.
- Предоставленные PNG: удалить 31 нижних пикселя; TIFF: 78. Это подготовленные параметры рабочей области данного набора, не детектор полосы для любых изображений.
- Маски, занимающие больше 85 % рабочей области, отбрасываются **до разрешения перекрытий**, независимо от флажка края; 100 % отключает этот фильтр. Это явная защита от маски всего поля, а не универсальный физический критерий зерна. Полные исходные предложения сохраняются в `proposals.npz`; вкладка 04 показывает карту после этой защиты.
- Сначала сохраняется крупнейшая связная компонента каждого исходного предложения. Отдельный ложный островок у края не удаляет внутреннее зерно.
- Край проверяется отдельно: все четыре стороны **рабочей области после среза**, до разрешения перекрытий. По умолчанию учитывается касание рамки и зазор в 1 px; отступ 0 означает точное касание. Выключение флажка оставляет краевые объекты. Результат содержит признак `touches_border`.
- Кнопка «Применить фильтры к маскам» перестраивает результат из сохранённых предложений без запуска нейросети. Она восстанавливает автоматическую геометрию; правки можно вернуть через Ctrl+Z. Классы неизменённых масок сохраняются.
- При пересечении оставшихся предложений пиксель получает маска с большей оценкой predicted IoU. Из фрагментов одного предложения сохраняется наибольшая связная компонента. Это стандартная фильтрация компонент, не обнаружение новой границы.
- Порог малых артефактов в эксперименте 16 px²; 0 полностью отключает его. Это не критерий среднего размера/формы. Малые реальные зёрна тоже могут быть потеряны; порог надо проверять на новых данных.
- Площадь относительно среднего, округлость и эксцентриситет **не используются для удаления**.

## Выходные данные

Каждая папка результата содержит:

| Файл | Содержимое |
| --- | --- |
| `labels.tif` | Текущая карта целочисленных ID, 0 — фон |
| `raw_labels.tif` | Карта кандидатов до отбора по краю/минимальной площади, после защиты от маски поля; ID независимы от итоговых |
| `classes.tif` | Семантическая карта: 0 фон, 1 зерно, 2 артефакт, 3 неопределено; словарь в JSON |
| `overlay_by_class.png` | Наложение с окраской по ручным классам |
| `grains.csv` | Все измерения и ручные классы, UTF-8 BOM |
| `session.json` | Параметры, статистика, SHA-256 исходника/весов, классы, оценки, происхождение и журнал |
| `session.npz` | Массивы для повторного открытия, без pickle |
| `proposals.npz` | Все исходные предложения SAM, упакованные по битам; форма хранится внутри |
| шесть PNG | Все промежуточные стадии и наложение |

Характеристики: площадь, центр (X вправо, Y вниз от верхнего левого угла), периметр Крофтона, большая/малая оси эллипса с теми же вторыми моментами, эксцентриситет, максимальный диаметр Фере, среднее и стандартное отклонение исходной яркости на внутренней границе, среднее/стандартное отклонение модуля градиента на ней. Последние величины описывают неоднородность границы, но не подтверждают её правильность. При масштабе длины умножаются на s, площади на s². Скалярный масштаб предполагает квадратные пиксели.

8-битные PNG и палитровые TIFF читаются через Pillow; 16-битные/вещественные серые изображения линейно нормируются по фактическому min/max. NaN/Inf отклоняются. Открывается первый кадр многокадрового TIFF. Исходные файлы не изменяются.

## Проверка качества и ограничения

В предоставленном архиве **нет эталонной разметки**. Поэтому в отчёте нет придуманных IoU/Dice/precision/recall. Число объектов, площадь и покрытие являются измерениями результата алгоритма, а не точностью сегментации. Программа может объединять соседние зёрна, делить неоднородное зерно, пропускать слабые границы и мелкие объекты. Сеть не дообучалась на SEM данного материала.

Для реальной оценки нажмите «Сравнить с эталонной маской». Формат эталона — двумерный NPY или TIFF с целыми ID, 0 — фон, по размеру **рабочей области**. Поле должно быть полностью размечено, включая принятую политику краёв. Цветной RGB-рисунок и частичная разметка без ignore-маски не являются подходящим эталоном. Метрики GUI считаются для текущего класса «Зерно»; эталон должен описывать те же объекты. Сохраняются бинарные IoU/Dice/precision/recall и объектный F1 с взаимно-однозначным сопоставлением при IoU ≥ 0.5. Бинарный IoU может быть высоким даже при слиянии нескольких зёрен; поэтому нужен и объектный F1. Любая правка сбрасывает прежние метрики.
